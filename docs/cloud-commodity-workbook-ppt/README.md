# 云商品平台产品经理学习成果 Web PPT

入口文件：

- `index.html`

辅助文件：

- `build-deck.mjs`：用于从 guizang-ppt-skill 瑞士风模板重新生成 `index.html`。
- `screenshots/`：关键页渲染截图，用于快速验收视觉效果。

## 使用方式

直接用浏览器打开 `index.html` 即可浏览。

快捷键：

- `←` / `→`：翻页
- `ESC`：打开索引视图
- `B`：切换静态/动态模式

## 风格说明

- 使用 `guizang-ppt-skill` 的瑞士国际主义风格。
- 主题色为克莱因蓝 IKB。
- 所有中文内容为 HTML 文本层，便于阅读、复制和后续调整。
- 图文配合主要通过时间线、矩阵、卡片、柱图、对比栏和系统关系图表达，不把中文文字烘焙进图片。
