# 云商品工作手册

> 本目录用于管理从 `cloud-commodity-workbook-outline.md` 扩写而来的完整工作手册。

## 目录

- `chapters/01-foundation-and-master-data.md`：基础概念、产品化前置、商品主数据、主数据治理、Offer/SKU/Meter/Price、Plan 权益。
- `chapters/02-lifecycle-channel-gtm.md`：生命周期、渠道发布、上下游协同、GTM、销售方案和报价前检查。
- `chapters/03-commercial-operations-governance.md`：财务商业化、SRE 门禁、客户解释、异常反向链路、发布后巡检、续约、组织指标和客户场景。
- `chapters/04-cases-platform-and-templates.md`：研发平台实现视角、ECS GPU/Seedance Mini/Agent Plan 三条案例、学习验收和模板清单。
- `templates/pm-copyable-templates.md`：产品经理可直接复制填写的核心模板。
- `audit/final-audit.md`：完整性、专业性、产品经理阅读友好性审计记录。
- `audit/subagent-findings.md`：subagent 专项审查发现与修复闭环。
- `audit/verification.log`：文件、章节、关键词和模板覆盖的结构化验收证据。

## 学习路线

### 30 分钟速读

1. 读本 README 的术语速查和最小产出包。
2. 浏览 `01` 的基础概念与主数据关系。
3. 浏览 `02` 的生命周期阶段作业卡和报价前检查。
4. 直接查看 `04` 的三条案例，建立业务闭环感。

### 2 小时入门

1. 精读 `01`：先分清能力、产品、商品、Offer、SKU、Meter、Price、Entitlement。
2. 精读 `02`：理解从产品化到渠道发布、GTM、销售成交的流程。
3. 精读 `03` 的财务、SRE、异常、巡检与续约章节。
4. 使用 `templates/pm-copyable-templates.md` 试填一个虚拟商品。

### 项目实战路线

按项目阶段查阅：产品化评审看 `01`；商品建模看 `01`；上架和渠道发布看 `02`；报价和 GTM 看 `02`；财务/SRE/客户解释看 `03`；发布后巡检和复盘看 `03`；案例对照和模板看 `04` 与 `templates`。

## 新手 PM 场景索引

| 我遇到的问题 | 先看哪里 | 先做什么 |
| --- | --- | --- |
| 销售催我今天给客户报价 | `02` 报价前检查、`templates` 报价模板 | 判断是估算、草稿还是正式报价；先确认价格、容量、SLA、折扣和合同边界 |
| 研发说能力已经 ready，可以上架 | `01` 产品化定义、`02` 生命周期 | 先做 readiness review，不要直接进入上架 |
| 运营要做大促活动页 | `02` 渠道发布、`03` SRE 门禁 | 检查价格、资源包、容量、限流、FAQ 和禁承诺项 |
| 客户投诉账单比预估高 | `03` 客户解释、异常 SOP | 核对订单、计量、价格、资源包抵扣和合同版本，用客户语言解释 |
| SRE 说某地域容量不足 | `03` SRE 门禁、`04` ECS GPU 案例 | 调整可售地域、交付窗口和销售话术，生成影响客户清单 |
| 财务说毛利不通过 | `03` 财务商业化 | 调整折扣、免费额度、资源包规则或审批路径 |
| 需要改 SKU、调价或退款 | `03` 异常反向链路、`templates` 变更影响分析 | 先出影响分析和审批摘要，再谈生产变更 |

## 产品经理最小产出包

新人读完后，不要求立刻写出完整 PRD，但至少应能产出 5 个工作件：

1. **一页产品化定义**：目标客户、核心场景、能力边界、不可承诺项、SLA 初稿、成本输入。
2. **一张商品模型图**：Product、Offer、SKU、Meter、Price、Entitlement、Region、Subscription 的关系。
3. **一份报价前检查清单**：价格口径、折扣、容量、SLA、合同、权益、账单解释是否可确认。
4. **一份发布后巡检表**：官网、控制台、订单、交付、计量、账单、客服、告警、客户反馈是否正常。
5. **一份客户解释话术**：估算不是正式报价、额度过期、失败扣费、合同价差异、地域不可售等问题的统一口径。

`templates/pm-copyable-templates.md` 已整理为 11 个核心模板，并补充 Seedance Mini、Agent Plan、ECS GPU 等填写样例。更完整的模板分类和使用场景可继续对照 `04-cases-platform-and-templates.md`。

## 术语速查

| 术语 | 简明解释 |
| --- | --- |
| Product | 商品主对象，回答“卖的是什么”。 |
| Offer | 售卖方案，回答“怎么卖”，如按量、包月、资源包、企业套餐。 |
| SKU | 可购买规格，回答“买哪一档”。 |
| Meter | 计量项，记录用量事实，如 Token、实例小时、GB、请求次数。 |
| Price | 价格规则，在 Product/Offer/SKU/Meter/Region/合同/生效时间等上下文中把用量转成金额。 |
| Entitlement | 权益规则，说明买后拥有什么额度、功能、席位、地域和有效期。 |
| Subscription | 客户当前购买并生效的订阅关系。 |
| GMV | 经营统计口径的成交规模，不等于净收入或收入确认。 |
| ARR/MRR | 年度/月度经常性收入，用于看订阅盘稳定性。 |
| Pipeline | 销售机会金额和推进阶段。 |
| SRE readiness | 商品可售前对容量、告警、限流、灰度、回滚、SLO/SLA 边界的门禁检查。 |
| GTM | Go-To-Market，把商品带到目标客户、渠道和销售场景的上市打法。 |
| IPD/PRD | 产品立项/产品需求文档，用于约束范围、里程碑和验收。 |
| Marketplace | 云市场或生态渠道，通常涉及伙伴上架、分佣、客户归属和售后责任。 |
| OpenUI/Domain Pack | 本手册平台视角中的实现示例命名，核心原则是展示契约和领域隔离，并非行业标准术语。 |

## 使用建议

- 不要把本手册当成一次性阅读材料；更适合在商品从 0 到 1 推进时按阶段查阅。
- 涉及收入确认、税务、发票、SLA 赔付、合同条款的内容，只提供 PM 应理解的边界，最终以财务、法务、SRE 和公司制度为准。
- 每次真实商品上架后，建议把项目产物沉淀回 `templates` 或案例章节，形成团队自己的商品化知识库。
