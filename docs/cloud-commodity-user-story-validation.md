# 云商品端到端用户故事验收剧本

这组剧本用于人工串联验证云商品 Agent 的端到端协同能力：从商品化、GTM、售前、报价、权限、账单、续约、运维事件到经营目标复盘。剧本不是业务 mock 数据，不代表真实云厂商价格、库存、SLA 或经营披露。

## 使用方式

- 在页面右上角切到“云商品”场景。
- 每个剧本按顺序连续提问，观察上下文是否保持在云商品域。
- 角色标签用于演示叙事；当前可切换账号以“商品 PM、老板、云销售、客户自助”为主，财务 BP、SRE、GTM、客户成功可先用商品 PM 或老板账号模拟。
- 每个剧本至少应出现两类 OpenUI 展示：KPI、图表、标签、风险列表、流程图、表格或证据来源。
- 回答不得泄漏工程字段，如 `cloud_*`、`owner_user_id`、`severity=high`、`arr_at_risk_cny`。

## 1. 新品上市前夜：Seedance Mini 自助购买上线

角色链路：商品 PM → 财务 BP → SRE → GTM → 老板

1. 商品 PM：`Seedance Mini 准备从产品能力商品化为可自助购买的云商品，IPD 上架前有哪些检查点还没完成？`
2. 财务 BP：`Seedance Mini 自助购买入口上线前，价格、资源包和合同折扣怎么做互斥？`
3. SRE：`Seedance Mini 大促生成队列健康度不够，应该怎么限流、告警和通知销售？`
4. GTM：`Seedance Mini 大促活动页需要哪些销售禁承诺项和数据边界提示？`
5. 老板：`Seedance Mini 上线如果延期一天，会影响哪些客户、GMV 和销售动作？`

验收重点：IPD 流程图、价格风险标签、容量/队列风险、不可承诺边界、延期经营影响。

## 2. Agent Plan 用量爆了：套餐毛利与客户体验冲突

角色链路：老板 → 财务 BP → SRE → 销售 → 客户自助

1. 老板：`Agent Plan 本月 GMV、pipeline、毛利和用量告警健康吗？最大风险是谁负责？`
2. 财务 BP：`Agent Plan 高成本模型、联网搜索和视频生成会不会把毛利打穿？`
3. SRE：`Agent Plan 用量告警翻倍，如何联动客服、销售和客户确认？`
4. 销售：`客户问 Agent Plan Medium 能保证多少轮对话，我应该怎么解释 AFP 假设和边界？`
5. 客户：`Agent Plan 套餐额度用完后会自动扣费吗？我要怎么确认超额付费？`

验收重点：GMV 漏斗、毛利标签、用量告警风险、人审/二次确认、客户友好解释。

## 3. 金融客户大单：ECS GPU + RDS + TOS 方案成交

角色链路：销售 → 解决方案 → 财务 → SRE → 老板

1. 销售：`金融客户预算 30 万，优先稳定性和可审计，ECS GPU、RDS、TOS、CLB 应该怎么组合？正式报价前要确认什么？`
2. 解决方案：`华东 1 和新加坡的 GPU 容量能支撑首批客户吗？如果容量不足，发布和销售应该怎么限制？`
3. 财务：`这个 ECS GPU 包月套餐的价格和折扣会不会影响毛利？哪些折扣不能直接给销售承诺？`
4. SRE：`如果新加坡 GPU 容量不足导致交付延期，影响哪些订单、GMV 和客户？给我回滚和客户沟通方案。`
5. 老板：`ECS GPU 商品本月 GMV 目标完成得怎么样？毛利、交付、容量和客户风险分别谁负责？`

验收重点：方案推荐、预算拆分、容量图表、折扣边界、运维事件经营影响。

## 4. 客户账单争议：从客户问题到经营风险

角色链路：客户自助 → 销售 → 财务 BP → 老板

1. 客户：`查询我能看的 2026 年 6 月账单和发票状态。`
2. 销售：`星河传媒集团这个月 CDN/TOS 账单有什么争议？我下一步该怎么跟客户解释？`
3. 财务 BP：`有哪些客户账单或发票有争议？影响金额是多少，谁负责解决？`
4. 老板：`云商品平台本月 GMV、净收入、毛利率、活跃客户和账单争议金额分别是多少？哪些指标需要解释为 demo 假设？`

验收重点：客户权限隔离、账单/发票状态、争议金额、负责人、demo/mock 边界。

## 5. 续约保卫战：重点客户 ARR 风险闭环

角色链路：老板 → 销售 → 客户成功 → 财务 → PM

1. 老板：`哪些重点云客户续约有风险，影响金额是多少？`
2. 销售：`我负责的云客户里，本周最该跟进哪三个机会？请按续约风险、金额和下一步动作排序。`
3. 客户成功：`Agent Plan 企业协作套餐如果延期，会影响哪些客户、GMV 和升级路径？`
4. 财务：`哪些客户应该强制开启超额付费二次确认，避免续约争议？`
5. PM：`把这些续约风险沉淀成下一次商品上架和客户成功检查模板。`

验收重点：续约风险金额、客户排序、负责人、下一步动作、复盘模板。

## 6. 组合产品售前：内容行业从询价到方案

角色链路：客户自助 → 销售 → GTM → 财务

1. 客户：`我想同时买 Seedance 和 Agent Plan，预算 2 万元，怎么分配更适合短视频批量生成和客服问答？`
2. 销售：`客户预算 18 万，要做电商商品图转短视频，Seedance Mini、TOS、CDN 怎么配？`
3. GTM：`为 Seedance Mini 生成 3 个行业方案：电商商品视频、品牌营销素材、UGC 创意测试。`
4. 财务：`Seedance Mini 促销价、资源包和合同折扣叠加后，毛利风险在哪里？`

验收重点：预算构成图、套餐估算、行业方案、报价边界、毛利风险。

## 7. 权限边界挑战：不同角色看同一个客户

角色链路：客户自助 → 销售 → 老板

1. 客户：`查询我能看的 2026 年 6 月账单和发票状态。`
2. 销售：`查询我能看的云客户续约风险和下一步跟进动作。`
3. 老板：`有哪些客户账单或发票有争议？影响金额是多少，谁负责解决？`

验收重点：客户只能看自己的账单；销售只能看自己可访问客户；老板可看经营汇总但不泄漏工程字段。

## 8. 上线复盘：从事故到下一次模板

角色链路：SRE → PM → GTM → 老板

1. SRE：`Seedance Mini 上线后如果生成失败率升高，商品页和销售话术应该怎么降级？`
2. PM：`生成 Seedance Mini 自助购买发布审批摘要，包含风险、人审、回滚和客服通知。`
3. GTM：`Seedance Mini 官网落地页应该放哪些 FAQ，避免客户把估算当正式报价？`
4. 老板：`把 Seedance Mini 从上架、销售、交付、经营风险复盘成下一次商品上架模板。`

验收重点：运维降级、审批摘要、FAQ、回滚检查点、复盘模板。

## 通用验收规则

- 每条剧本至少连续跑 4 个问题，观察上下文是否保持在云商品域。
- 每个剧本至少出现 2 类 OpenUI：指标、图表、标签、风险、流程、表格、证据来源。
- 估算/报价必须说明公式、假设、边界、置信度和“非正式报价”。
- 老板类问题必须说明结论、GMV/毛利/风险、影响金额/客户、负责人、下一步动作和证据来源。
- 写入类动作只能生成草稿、审批摘要或模拟计划，不得表现为真实生产变更。
