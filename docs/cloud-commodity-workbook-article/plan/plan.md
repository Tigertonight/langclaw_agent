# Plan

## Brief

- 目标读者：云商品产品经理、平台产品经理、GTM/销售方案 PM，以及需要系统学习“技术能力如何变成可售云商品”的业务负责人。读者带着两个问题进入：第一，云商品主数据、生命周期、渠道、财务、SRE、客户成功之间如何协同；第二，自己在真实项目里应该交付什么、找谁确认、在哪些风险点停下来。
- 目标语言：中文，跟随源材料；保留 Product、Offer、SKU、Meter、Price、Entitlement、GTM、SRE、GMV、ARR 等英文术语，但第一次出现时给出中文解释和业务语境。
- 文章类型：longform。
- 信息保留比例：100%（longform 标配）。这是完整工作手册，不做决策摘要或传播版裁剪。
- 必须保留的信息：
  - `README.md` 的学习路线、第一周任务、角色路线、新手 PM 场景索引、最小产出包和术语速查。
  - `01-foundation-and-master-data.md` 的能力/产品/商品边界、产品化 readiness、主数据实体、主数据治理、Offer/SKU/Meter/Price、Plan 权益、三类小案例和 PM 检查清单。
  - `02-lifecycle-channel-gtm.md` 的生命周期全流程、阶段作业卡、渠道发布矩阵、GTM、销售方案、报价前检查、客户分层、禁承诺项和阻塞处理。
  - `03-commercial-operations-governance.md` 的财务商业化、收入确认、SRE 门禁、客户自助与售后解释、异常反向链路、发布后巡检、续约客户成功、组织层指标和外部客户场景。
  - `04-cases-platform-and-templates.md` 的平台实现视角、ECS GPU、Seedance Mini、Agent Plan 三条案例、学习验收和 11 个模板清单。
  - `templates/pm-copyable-templates.md` 的 11 个可复制模板和 5 个填写样例。
  - `audit/final-audit.md`、`audit/subagent-findings.md`、`audit/verification.log` 的覆盖矩阵、已修复问题、仍需业务方校准和验收证据。
- 可删减的信息：默认不删减。仅在最终文章排版时允许把重复的文件路径说明、日志类证据折叠为附录或 disclosure，理由是它们服务可追溯性，不应该抢占正文学习路径；内容本身仍保留。
- 语气：专业、克制、教学型工作手册。每个概念先讲业务含义，再讲交付物、负责人、风险和检查清单。
- 主要观点：
  - 云商品不是“页面上架”，而是产品定义、商品主数据、渠道发布、计量计费、财务收入、SRE 稳定性和客户成功的协同系统。
  - Product / Offer / SKU / Meter / Price / Entitlement 是商品中台的骨架；变更任一环节都会影响渠道、订单、合同、账单和客户解释。
  - 一个合格的云商品 PM 不只会写 PRD，还要能拉齐财务、SRE、法务、GTM、销售、客服和老板视角的经营闭环。
- 阅读目标：读完后，读者可以复述云商品从能力到产品、从产品到商品、从商品到经营闭环的全流程；能产出一页产品化定义、商品模型、报价前检查、发布后巡检、客户解释话术和经营健康简报；能识别 Plan 型产品、渠道一致性、反向链路、SRE 门禁和财务商业化中的高风险点。
- 版式宽度：wide。源材料包含大量表格、模板、矩阵和清单，常规宽度会降低可读性。
- TOC：开。文章是长手册，需要左侧目录帮助学习和回查。
- 配图策略：none。第一版不使用外部 Image，靠正文、表格和 Raw 自由层做结构图、关系图、流程图和矩阵；这样更像可离线阅读的业务手册，且避免图片抢正文。
- 封面：开。建议使用 Tufte 风格的 3:4 书封，模板 C（上下分屏）：上半为标题与副题，下半用细线 SVG 表达“能力 → 产品化 → 商品主数据 → 渠道/交易 → 经营巡检”的闭环地图。

## Theme

- 选定主题：tufte。
- 理由：源材料是证据型、表格型、流程型的长手册，重点是阅读、查阅和复盘，而不是营销展示。Tufte 的低装饰、高数据墨水比适合保留大量表格、矩阵和检查清单。
- 与源材料的冲突：源材料含较多 PM 模板和案例，可能比传统 Tufte 更“操作手册”。处理方式是保持正文克制，但在关键章节使用 Raw 做细线图解、流程、关系图，增强理解而不变成卡片堆叠。
- 当前信息密度下的表现建议：正文为主体，Raw 只用于“能力到商品”“主数据关系”“生命周期泳道”“渠道矩阵”“财务/SRE/客户旅程”等高认知负荷位置；所有表格保留，但长模板和审计日志放入附录或 disclosure，避免打断主叙事。
