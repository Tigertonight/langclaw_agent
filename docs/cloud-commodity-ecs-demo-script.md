# ECS GPU 云商品全链路演示脚本

定位：面向云厂商售卖的“通用云商品平台 Agent”。ECS GPU 训练实例是演示商品，所有价格、容量、毛利、GMV 和事件影响均为 demo/mock 数据，不代表任何云厂商正式承诺。

## 15 分钟节奏

### 1. 商品 PM：IPD 到商品模型

演示问题：

“我要把 ECS GPU 训练实例接入云商品平台，支持华东 1 和新加坡，按量和包月售卖。请生成商品模型、SKU、计费项、购买页字段和 IPD 上架检查清单。”

讲解重点：

- Agent 把资源能力拆成 Product、Offer、SKU、Meter、Price、地域和购买页字段。
- IPD 检查点显示商业测算、容量评审、SLA 文案和 GTM ready 的状态。
- 价格、容量、SLA 均只生成草稿和评审建议，不自动生效。

### 2. 商品 PM：发布审批

演示问题：

“生成 rel_ecs_gpu_train_202606 的发布审批摘要，重点看价格、容量、SLA 和回滚检查点。”

讲解重点：

- 发布申请进入风险审查。
- 财务卡在毛利底线，SRE 卡在新加坡容量，法务卡在 SLA 承诺边界。
- 回滚方案是关闭新购入口、保留存量权益、恢复价格和购买页快照。

### 3. 财务 BP：毛利和折扣边界

演示问题：

“这个 ECS GPU 包月套餐的价格和折扣会不会影响毛利？哪些折扣不能直接给销售承诺？”

讲解重点：

- GMV 接近达成不等于经营健康，净收入和毛利会被大客户折扣、资源包抵扣和 GPU 成本上升拉低。
- 销售不得承诺低于毛利底线的包月折扣，必须走财务审批。

### 4. SRE：容量和限售

演示问题：

“华东 1 和新加坡的 GPU 容量能支撑首批客户吗？如果容量不足，发布和销售应该怎么限制？”

讲解重点：

- 华东 1 可灰度开放但需要安全缓冲。
- 新加坡只能容量预约，不承诺固定交付日期。
- Agent 把 SRE 口径同步到发布、销售和合同边界。

### 5. GTM/运营：销售包

演示问题：

“帮我生成 ECS GPU 训练实例的 GTM 包：目标客户、卖点、FAQ、销售话术、不能承诺的边界。”

讲解重点：

- 目标客户分为 AI 训练客户和金融核心系统客户。
- GTM 包包含目标客户、话术、FAQ、方案包和不可承诺项。
- 不可承诺项包括固定库存、未经审批折扣、固定交付日期和固定算力可用性。

### 6. 云销售：金融客户方案

演示问题：

“金融客户预算 30 万，优先稳定性和可审计，ECS GPU、RDS、TOS、CLB 应该怎么组合？正式报价前要确认什么？”

讲解重点：

- ECS GPU 做训练主负载，RDS 做业务数据库，TOS 做训练数据和审计材料，CLB 做业务入口。
- 正式报价前确认地域容量、GPU 规格、SLA、折扣审批和审计要求。

### 7. 客户自助：询价边界

演示问题：

“我想买 ECS GPU 训练实例，预算 10 万，华东 1 包月，大概能买什么规格？价格是不是正式报价？”

讲解重点：

- Agent 可以给预算拆分和配置建议。
- 必须明确这是估算草稿，不是正式报价、库存承诺或交付承诺。

### 8. 老板：GMV 目标驾驶舱

演示问题：

“ECS GPU 商品本月 GMV 目标完成得怎么样？毛利、交付、容量和客户风险分别谁负责？”

讲解重点：

- 展示目标、已成交、目标缺口、加权 pipeline、净收入、毛利率、延期订单和容量健康度。
- GMV 看似能覆盖目标，但毛利和收入确认仍有风险。
- 输出负责人和下一步动作。

### 9. 运维事件：经营影响

演示问题：

“如果新加坡 GPU 容量不足导致交付延期，影响哪些订单、GMV 和客户？给我回滚和客户沟通方案。”

讲解重点：

- 运维事件不只影响 SRE，也影响 GMV 计入、收入确认和客户满意度。
- Agent 生成影响订单、客户沟通草稿、回滚检查点和处理动作。

### 10. 复盘：沉淀下一次模板

演示问题：

“把 ECS GPU 从立项到上架、销售、交付、经营达成的阻塞复盘成下一次商品上架模板。”

讲解重点：

- 把阻塞前置为下一次商品上架模板：毛利底线、容量预约、SLA 边界、GTM ready、销售报价检查和运维事件经营影响。
- 展示 Agent 是跨商品、销售、财务、SRE、老板和客户的协同工作台。

## 当前数据边界

- ECS GPU 价格、容量、毛利、pipeline、GMV 和运维事件是演示样本。
- 火山引擎只作为 demo provider，domain 和工具命名保持通用云商品平台表达。
- 第一阶段不接真实生产系统，不执行真实上架、价格生效、退款、审批通过或容量变更。
